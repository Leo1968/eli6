Steps to use the eli6-extension

Open the Google Chrome browser, type `chrome://extensions/` into the address bar, and press Enter.

Toggle on "Developer mode" in the top-right corner.

Click "Load unpacked" in the top-left corner and select the `eli6-extension` folder you just created.

Go to the extension's "Options" page, enter the API key for your AI model, and save the settings.

Click "Details" on the extension card.

Locate "Extension options" or "Options" on the details page.

Fill in the following:
- API Endpoint: `https://api.openai.com/v1/chat/completions`
- API Key: Enter the key obtained from OpenAI or another service provider
- Model Name: `gpt-4o`

Click "Save Configuration."

Select any text on a webpage, right-click, and choose "Visualize selection with ELI6"; an interactive, downloadable HTML diagram will be instantly generated in the sidebar.




eli6-extension使用步骤


打开 Google Chrome 浏览器，在地址栏输入 chrome://extensions/ 回车。

打开右上角的 “开发者模式”（Developer mode）开关。

点击左上角的 “加载已解压的扩展程序”（Load unpacked），选择刚刚创建的 eli6-extension 文件夹。

点击插件的“选项”页，填入你使用的AI模型 API Key 并保存。

点击插件卡片上的 “详情”

在详情页面中找到 “扩展程序选项” 或 “选项”

填写：
- API 接口：https://api.openai.com/v1/chat/completions
- API Key：填入你在 OpenAI 或其他服务商获得的密钥
- 模型名称：gpt-4o

点击 “保存配置”

在网页上选中任意文字，右键点击 “用 ELI6 视觉图解选中内容”，侧边栏便会即时生成可交互、可下载的 HTML 架构图解。
